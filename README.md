## Bedrock export

The `.mcaddon` export is generated by `src/export/` and has to match the resource pack in `base/`.

- `npm run verify:export` runs the exporter in Node and compares every JSON file with `base/`.
- `npm run sync:base` copies `base/particles` into `public/particles` (`-- --textures` also copies PNGs, `-- --check` only lists differences).
- Pack-level constants (UUIDs, materials, lighting, texture sets, static file list) live in `src/config/pack.js`.
